## Воркшоп #1: Введение и настройка инструментов

**Тема:** Вводная встреча — экосистема AI-инструментов, регистрация, покупка подписок

**Инструменты:** Perplexity Pro, Grok, ChatGPT, Claude, Z2U, GGCell, Comet Browser

**ДЗ:** Зарегистрироваться на Z2U, купить Perplexity Pro + Grok, установить ChatGPT на телефон, Comet Browser

**Ключевое:** B2B стратегия через LinkedIn (50 аккаунтов), сообщество «AI-задроты»

## Воркшоп #2: Мышление и промт-инжиниринг

**Тема:** Трансформация мышления при работе с AI. Не количество инструментов, а правильный менталитет

**Инструменты:** ChatGPT, Google Gemini, NotebookLM, Perplexity, WhisperFlow, Custom GPTs, Suno

**Методологии:**
- **7 навыков AI-мышления:** насмотренность, экспериментирование, дробление на шаги, итеративность, контекстное окно, позиция незнания, быстрое выделение сути
- **Фреймворк полуавтоматизации:** NotebookLM = память, Gemini = мозг
- **Промт-методология:** каждый промт индивидуален, `think step by step` и `ultrathink`

**ДЗ:** Собрать 2–3 юзкейса, сравнить промты старым/новым методом, практика «Почемучка»

**Ключевое:** Исследование: +25% скорость, +12% задач, +40% качество с AI. «95% задач решаю 3–4 инструментами»

## Воркшоп #3: AI-ассистенты

**Тема:** Создание и архитектура AI-ассистентов для бизнеса

**Инструменты:** ChatGPT (GPTs), Claude Projects, Google Gems, NotebookLM, Claude Code, AI Studio, Humanizer скилл

**Методологии:**
- **Jobs-to-be-done:** вход → бизнес-задача → выход
- **Лестница Бена Ханта** (уровни осознания проблемы)
- **Различие:** ассистент (реактивный) vs агент (проактивный)
- **Техника «надрачивания»** — итеративная подгонка
- **Скиллы (вертикаль) + проекты (горизонталь)** = многомерный ассистент

**ДЗ:** Определить нужных ассистентов, создать первого, показать сотрудникам, воспроизвести голосового, сделать многомерного

**Ключевое:** Демо — тренажёр отдела продаж, консультант по нарциссам (166 видео в NotebookLM)

## Воркшоп #4: Deep Research

**Тема:** Глубокое исследование рынка, аудитории и конкурентов для стратегических решений

**Инструменты:** Perplexity (Academic/Social), ChatGPT Deep Research, Parallel AI, Claude, Gemini, NotebookLM

**Методологии:**
- **Трилема бизнеса:** голос рынка / голос аудитории / голос конкурентов
- **5-этапный Deep Research:**
  1. Загрузка контекста (ДНК бизнеса)
  2. Мета-промптинг
  3. Мультивселенная (параллельный запуск)
  4. Синтез в NotebookLM
  5. Выводы
- **Стратегия против галлюцинаций:** требовать источники → загружать в NotebookLM → работать только с источниками

**ДЗ:** Провести полный Deep Research своего проекта по 3 направлениям

**Ключевое:** Пример — курс AI для детей. «Нейросети — чемпионы по вранью, поэтому нам нужны источники»

## Воркшоп #5: Маркетинг (ДНК клиента + оффер + лендинг)

**Тема:** Создание уникального оффера и прототипа лендинга на основе ДНК клиента

**Инструменты:** Claude, Google Gem, Claude Code, NotebookLM, OpenCLO, Meta Ads, Google Forms, Telegram Desktop, Notion, 11Labs, Lovable

**Методологии:**
- **3 источника данных о ЦА:**
  - Синтетические (Deep Research)
  - Реальные (CustDev 5–10 интервью)
  - Telegram (выгрузка чатов)
- **ДНК клиента — 5 частей:**
  1. Сегменты
  2. Боли/страхи/триггеры
  3. Психология покупателя
  4. Потребности
  5. Готовность платить

**Структура лендинга — 10 блоков:**
1. Главный
2. Боль
3. Решение
4. Результат
5. Соцдок
6. Оффер
7. Бонусы
8. Цена с якорем
9. Гарантия
10. CTA + FAQ

**AI-ассистенты этого урока:** ДНК клиента, Alex Hormozi (оффер), лендинг

**ДЗ:** Создать ДНК клиента → оффер через Hormozi → текстовый прототип лендинга 10 блоков → кросс-чек

**Ключевое:** «Самое ценное — ассистенты и инструкции к ним»

## Воркшоп #6: Создание лендингов

**Тема:** Практический мастер-класс — от ТЗ до публикации лендинга с AI

**Инструменты:** Claude Code (основной для кода), Google AI Studio (Nano Banana Pro), FlowWith.io, Grok (анимация), Vercel, Gemini, ChatGPT

**Методологии:**
- **VSL структура лендинга**
- **Интерактивные элементы:** калькуляторы, ROI-слайдеры, квизы, дашборды
- **Lead Magnet стратегия** (3-слайдовый квиз)
- **Архитектура:** домен ≠ хостинг, субдомены
- **Параллельная генерация изображений**

**ДЗ:** Создать лендинг в Claude Code, сгенерировать изображения, задеплоить на домен

**Ключевое:** «Claude Code — единственный инструмент для кода. Аналоги — жалкое подобие»

## Воркшоп #7: AI-агенты (OpenCLO)

**Тема:** Революционная технология OpenCLO — AI-агенты, которые работают автономно

**Инструменты:** OpenCLO (25,243+ скиллов), Claude Opus/Sonnet, Gmail, Telegram, LinkedIn, Fireflies, n8n, Apify, Claude Code

**Методологии:**
- **Архитектура OpenCLO:** память (daily notes + long-term + semantic search), крон, субагенты, скиллы, API
- **3 уровня обучения агента:**
  1. «Делай это»
  2. «Научись делать»
  3. «Научись учиться»
- **Формирование кейсов** через тренажёр (интервью → список автоматизаций)

**ДЗ:** Установить OpenCLO, сформировать кейсы через тренажёр, начать общение с агентом

**Ключевое:** «Opus и Sonnet — с ними имеет смысл работать. Всё остальное — шляпа деревянная»

## Воркшоп #8: Вайб-кодинг

**Тема:** Разработка ПО с AI — Claude Code, GitHub, Railway

**Инструменты:** Claude Code (Opus 4.6), Cursor, GitHub, Railway, Google AI Studio, Perplexity API, Instagrampy, gspread, python-telegram-bot

**Методологии:**
- **6 шагов вайб-кодинга:**
  1. Промт + контекст + задача
  2. План
  3. Согласование
  4. Реализация по шагам
  5. Тест
  6. Проверка
- **Формула промта:** кто я → контекст → задача → формат
- **GitHub workflow:** repo → commit → stars → fork
- **Полный цикл:** GitHub (библиотека) → Claude Code (разработка) → GitHub (сохранение) → Railway (деплой)

**ДЗ:** Создать Instagram DM бота, задеплоить на Railway

**Ключевое:** 193 строки кода за **~31 секунду**. «Вайб-кодинг — ваша Формула-1». UltraThink и YOLO режимы. 5 рецептов автоматизации Instagram.
