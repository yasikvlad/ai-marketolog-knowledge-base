## Ключевые проблемы и решения

### 1. Обход блокировок и оплата
- **Z2U** для дешёвых подписок (возвраты, отмены заказов)
- **VPN** (США/Европа), инкогнито, очистка cookies, смена DNS для заблокированных сервисов

### 2. Контекстное окно и галлюцинации
- **NotebookLM** как внешняя «память», **Claude/Gemini** как «мозг»
- **Скиллы (Skills)** для автоматического обращения к базе знаний
- Не перегружать контекстное окно

### 3. Автоматизация маркетинга и продаж
- API Instagram для анализа 10 000+ переписок
- Генерация «ДНК клиента»
- Лестница Бена Ханта для контент-планов
- Парсинг конкурентов через агентов

### 4. Интеграция с локальными программами
- **Excel-дашборды** через Claude-плагины
- **CRM (1C, Zoho, Bitrix)** через API и вебхуки

### 5. Безопасность (Prompt Injection)
- VPS, песочницы, изоляция API-ключей
- Проверка сторонних скиллов на вредоносный код

## Ключевые вопросы участников

### Промпты
- Как оценить сложность задачи для промта?
- Откат назад (rewind) вместо переписывания
- «Метод Сократа» — заставить AI задавать вопросы
- Столкновение нейросетей в дебатах

### AI-ассистенты
- **Тренажёр для менеджеров по продажам** — реализовано в прямом эфире
- **AI для HR-собеседований** — через Google AI Studio + Lovable + Claude Projects

### Deep Research
- Поиск скрытых цен конкурентов: парсинг, PDF-прайсы в NotebookLM, агенты-разведчики
- Анализ Telegram-каналов: экспорт JSON → NotebookLM

### OpenCLO
- Telegram vs веб-чат (Telegram = интерфейс к серверу)
- OAuth-ключи в терминале — безопасность
- Лимиты трат токенов (день/неделя)

### Будущее бизнеса
- AI заменит традиционные CRM: **LTV-loop экосистемы** вместо воронок
- Агенты сами коммуницируют с клиентами
